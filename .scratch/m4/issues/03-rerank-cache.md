# 03: 停鍵結果快取

Status: done
Blocked by: 02
讀: plan §2.1（`rerank_request` / `apply_rerank`）、§2.7、§3.1（停鍵層）；spec〈共同規則〉

## What to build

同一串輸入碼的重排結果留快取（plan §2.7，青簡做法；M3 沒做）：退格回到已經算過的那串碼時，直接套用快取的結果，不再等停鍵、不再跑模型。

快取的鍵要涵蓋會改變結果的一切（輸入碼、前文、選定的分段等，由票列出）：其中一項變了就不能用舊結果。快取放核心還是殼，由票定並寫進 plan §2.7。
