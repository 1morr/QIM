# 14: 學習：使用者詞、自動造詞、匯出匯入

Status: ready-for-agent

讀: plan §2.1（`export` / `import`）、§2.4（規則 1、3、自動造詞、匯出格式）、§3.1（`localStorage`）、§5.1；brief §1.5、§4.5、§5.3（使用者詞庫格式帶版本）；spec〈共同規則〉

## What to build

使用者能手動加詞與觸發詞；分段選字上屏後自動學成使用者詞；學習資料重新整理網頁後還在，也能匯出成 TSV、再匯入。

- 規則 1：觸發詞完全符合的使用者詞 → 首選。規則 3：上屏次數 ≥ 1 的使用者詞（含自動造詞）→ 至少第 2 位。
- 自動造詞：一次組字分兩段以上選定後上屏，把整串輸入碼 → 上屏文字記成使用者詞，上屏次數 1（plan §2.4）。
- 匯出格式 `# qim-userdict v1` TSV：欄位照 plan §2.4（方案、詞、輸入碼、計數、最後 tick、來源、觸發詞）。這是對外格式，定稿前對照 libime 文字碼表與 Rime userdb 文字匯出，採用了誰的慣例寫回 plan §2.4；之後改格式要升版本（brief §5.3）。
- `UserModel::export` / `import`；`export` 後 `import` 等價（性質測試）。
- 網頁：手動加詞（詞、觸發詞）的介面、匯出與匯入按鈕；學習資料存 `localStorage`，載入時匯入。

## 驗收

- [ ] 核心測試：在 `mir` 分段選「一」「台」後，下次 `mir` 的「一台」在第 2 位，再選一次成首選。
- [ ] 核心測試：手動加的使用者詞打觸發詞時是首選。
- [ ] 性質測試：`export` 後 `import` 等價；匯出檔第一行是 `# qim-userdict v1`。
- [ ] plan §2.4 的匯出格式已定稿並寫明參考了誰。
- [ ] Playwright：分段選字上屏後重新整理網頁，讀回學到的詞仍在第 2 位；匯出、清空、匯入後讀回相同。
