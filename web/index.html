        常用語

          打觸發詞時它是首選；沒有觸發詞的從候選列的「常用語」選。

          英文使用者詞

            用英文打過、4 個字元起的字串（含 email、數字）會學在這裡。英文詞典沒有的打過 2 次後，在中文打整串時排第 2；打過 3 次又是最常用的 20 條之一時，打開頭 3 個字母就有（詞典有的詞不給）。一年沒打的不再出現；無痕、學習關掉時不學。

            匯入詞庫

            收 Rime 碼表（.dict.yaml）、Gboard 個人字典的 dictionary.txt（先解壓匯出的 zip）、一行一詞的純文字。碼由字推出，Gboard 的快捷鍵預設不設成觸發詞（確認時可勾選）；詞是加進使用者詞，不動原本的學習資料。

                  資料包

                  使用種類名稱版本大小授權來源

                  一起選資料包目錄裡的 manifest.json 與 .pack 檔；核對過大小、sha256 與核心版本才收，匯入後那一種改用它。

                  開著時每次開網頁在背景檢查 GitHub Releases 有沒有裝著的資料包的新版，核對過 sha256 才換上；失敗時照用現有的。關掉就不連線。

                  匯入會把檔案合併進目前的學習資料：兩邊的次數相加，對方刪掉的這裡也刪。要同步兩個瀏覽器或裝置，各自匯出、再匯入對方的檔。

                  從備份還原會換成備份的內容，並留一個清空記號：同步到別台後，別台原本的學習資料也換成這份備份。

                  清空會同步到別台：別台匯入這台的檔時，它在收到清空之前學的也一起清掉，包括這台清空後、同步前才學的。想留的先匯出。
