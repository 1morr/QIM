# 黑箱基線：macOS、iOS 內建速成與 Gboard

實測日期：2026-11-04。Apple 兩者在票 `.scratch/m1/issues/08-blackbox-apple.md`，Gboard 在票 `.scratch/m1/issues/09-blackbox-gboard.md`。照 `docs/research/closed-source-imes.md` §4 的 T1–T18，只打字、讀回畫面，不開產品的檔案、不逆向（ADR 0006）。

截圖在 `.scratch/m1/evidence/`，檔名以 `08-mac-`、`08-ios-`、`09-android-` 開頭；下文寫成 `ev/<檔名>`。

和測試表通用準備不同的地方：

- 沒有先清學習資料。macOS 的速成測前沒啟用；iOS 不重設鍵盤字典，因為會刪掉使用者自己的學習資料。兩邊都用測前沒選過的碼做 T3、T16。
- 結果固定的項目只打 1 次；T3 / T4 / T16 照表重複，T9 跑 3 次。
- 沒有 240 fps 錄影，T9 的量法見下。
- 沒重啟電腦與手機（T14）：重啟會中斷使用者正在用的機器與這次測試的連線，iPhone 重啟後還要使用者在手機上重新授權 `iphone-use`。
- 沒改輸入法設定，所以沒測「關掉預測或詞頻調整後是否仍前移」（T3）。

T5 系列對 `closed-source-imes.md` §3 四個假設的結論：

- H1 個人學詞：**成立**，只在英文鍵盤。打 3 次後兩輪學到、一輪沒有，跨 App、離線都有效，但觸發不穩，而且這台上重開就沒了。
- H2 Autofill：**排除**。關掉 autofill 服務照樣出，外觀是一般建議，不分 email 欄與一般欄。
- H3 帳號 / 聯絡人：這台沒有 Google 帳號與聯絡人，「Suggest contacts」也預設關，所以測不到；不能排除真機上另有這個來源。
- H4 剪貼簿：**是另一個東西**。剪貼簿內容以帶圖示的晶片在聚焦時出現，打前綴不會補成它。

使用者在真機上觀察到的「記得 email」，最可能是 H1 加上真機會存檔（這台模擬器重開就沒了，原因沒查出）；有登入帳號時可能還有 H3。
