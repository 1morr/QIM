# 速成碼在建置資料包時推導，每個輸入方案只索引自己的碼

速成碼在建置資料包時由倉頡碼推導，存成速成輸入方案自己的碼表；執行時核心只查這份碼表，倉頡碼不是速成的合法輸入碼。Rime 的做法相反：速成方案載入倉頡全碼表，執行時用 `derive` 另加首尾碼，全碼仍然有效且不降權，這正是使用者回報的 `anr` 首選「問」、連打碼等於倉頡碼時該字排第一的根因（`docs/research/rime.md` §4）。看到倉頡碼表就想在執行時推導的人，請先讀這份。

## Consequences

- 加入倉頡輸入方案時，它有自己獨立的碼表，與速成互不滲透。
- 三代與五代推導出的速成碼都收進速成碼表（brief §4.2），這是兩套速成碼的聯集，不是讓倉頡碼滲入。
